🌿 WildLife App

WildLife App is a modern Android application built using Java and XML.
The app demonstrates clean UI design, Fragment-based navigation, Navigation Drawer integration, and Bottom Navigation handling following Material Design principles.

📱 Features

🏠 Home Screen with wildlife content

👤 Profile Screen

❤️ Favorites Section

🔍 Search option in Toolbar

📂 Navigation Drawer

🔽 Bottom Navigation Bar

🎨 Custom Toolbar Icons

🌈 Status Bar color management

📱 Fragment-based navigation

🧭 Material Design UI

🛠️ Tech Stack

Language: Java

UI: XML

Architecture: Fragment-Based

Navigation: BottomNavigationView, DrawerLayout

Design: Material Components

IDE: Android Studio

🚀 How to Run

Clone the repository:

git clone https://github.com/Pankaj08072001/WildLifeApp.git

Open in Android Studio

Sync Gradle

Run on Emulator or Physical Device
